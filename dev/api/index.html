API

The operator

PartialFSHT.Plan — Type
Plan(θ, φ; lmax, tol=1e-10, spin=0, ntrans=1, method=AutoAlgorithm(),
     backend=SerialBackend(), nufft=AutoNUFFT(), maxboxes=8,
     fft_threads=1, oversample_θ=1, oversample_φ=1, εapo_max=1.0)

Reusable transform for colatitudes θ ∈ [0,π] and longitudes φ ∈ [0,2π).

method is an AbstractAlgorithm; AutoAlgorithm picks by counted cost. With MPIBackend, θ/φ are the rank-local points: synthesis writes the local field and the adjoint Allreduces coefficients, so passing the global point set on every rank would scale the adjoint by the communicator size.

The rest is leaf tuning, forwarded to leaves that use it:

  • fft_threads — FFTW planner threads for this package's plans. One by default, because a multithreaded FFTW plan spawns Julia tasks on every execution and would make each apply allocate; the ring pass is threaded directly instead.
  • nufft_kwargs — passed through to the NUFFT plan builder. nufft_kwargs = (nthreads = 1,) makes a FINUFFT apply strictly allocation-free: its internal FFTW plan otherwise inherits its own OpenMP thread count and executing it spawns Julia tasks through FFTW.jl's callback — measured 4 kB per apply at lmax = 512 and 900 kB at lmax = 1024, against roughly twice the NUFFT time when pinned. Which side of that trade is right depends on whether a solver's churn or its throughput matters more, so it is not decided here.
  • oversample_θ, oversample_φ — grid inflation over the derived bandlimit. Oversampling only improves the trigonometric interpolation, so these exist for calibration sweeps.
  • εapo_max — largest apodisation fraction the stretched construction is used at.

PartialFSHT.solve! — Function
solve!(alm, plan, f; mode=:cg, rtol=1e-6, maxiter=500, prior=nothing, w=nothing, ws=…)
    -> (alm, info)

Coefficients from partial data. A†A is rank-deficient by construction, so there is no regularisation-free answer and mode must be chosen, not defaulted past:

  • :cg — conjugate gradients on the normal equations, stopped at rtol. The stopping rule is the regularisation, so info.iters is part of the answer.
  • :wiener — Tikhonov with a stated prior (C_ℓ), i.e. the Wiener filter. What a CMB pipeline or an assimilation step means by "solve", and the right choice when a background exists.
  • :minnorm — minimum-norm least squares. Optimal for anything evaluated inside the region; its field decays outside over the reproducing-kernel scale ~1/L, so it is the wrong choice if the coefficients then feed a global quantity.

info carries shannon, Δℓ, iters, relres and mode, because a coefficient array from partial data is not interpretable without them. Allocation-free after ws is built.

PartialFSHT.spectrum — Function
spectrum(plan, f, w, Wℓ; Δℓ=nothing, deconvolve=true, ws=…) -> NamedTuple

Band-powers from data on a region, with the mask coupling accounted for.

Returns bands, bandpowers, sigma — the √(2/((2ℓ+1) f_sky Δℓ)) scatter, which is the price of partial sky: variance, not bias — the binned coupling Mb, and the raw pseudo-spectrum.

deconvolve = false leaves the estimate in pseudo space, which is the preferred comparison direction: push a model spectrum forward through Mb rather than inverting it. Inversion is a convenience for plotting in truth space, not a requirement.

coupling accepts a M_{ℓℓ'} from mask_coupling. It is O(L³) and a function of the mask alone, so anything looping over realisations or over batch members should build it once and pass it here rather than have every call rebuild it. backend is used for that build.

PartialFSHT.recoverability — Function
recoverability(θ, φ, lmax) -> NamedTuple

What a geometry can support, computed from the geometry alone: fsky, the Shannon number N_S = (lmax+1)² f_sky, the recoverable fraction of coefficient directions, and the spectral resolution Δℓ ≈ π/Λ.

Two facts this is meant to make unmissable. The recoverable fraction is f_sky independently of ℓ — more wavelengths across the patch improve the spectrum but never the fraction of individually determined coefficients, because higher ℓ brings proportionally more of them. And the useful output is banded: a 4° patch resolves Δℓ ≈ 45, a hemisphere Δℓ ≈ 1.

source
PartialFSHT.apply_resolution! — Function
apply_resolution!(out, plan, alm, w, ws) -> out

Push a coefficient set through the same filter the data saw: out = A† W A alm, with W the per-point weight. This is the operator any comparison against partial observations must use on the model side, so both sides carry identical coupling and nothing needs deconvolving.

Two transforms, expressed entirely in Y_{ℓm}, and the operator a third party needs to reproduce a published comparison — apply it to their own field, then compare.

PartialFSHT.polar_mmax — Function
polar_mmax(θ, lmax, ε; pad_factor=polar_pad_factor()) -> Int

Largest order that must be retained on a ring at colatitude θ for a degree-lmax transform at relative tolerance ε.

P̄_ℓ^m(cosθ) turns from oscillatory to evanescent at m ≈ ν sinθ with ν = ℓ+½. Past the turning point the Bessel/Airy form gives |P| ~ exp(-m(2δ)^{3/2}/3) with δ = m/(ν sinθ) - 1, so reaching a relative level ε needs

m - ν sinθ  ≳  ½·3^{2/3} (ν sinθ)^{1/3} ln(1/ε)^{2/3}.

The transition width grows like ℓ^{1/3} ln(1/ε)^{2/3} — it is not a constant. At ℓ = 4096, θ = 0.394, ε = 10⁻⁸ it is 85 orders, so a fixed pad silently over-truncates at high degree.

Geometry and periodisation

PartialFSHT.SphereBox — Type
SphereBox{T}

Minimal colatitude × longitude box containing a point set.

  • θlo, θhi — colatitude extent
  • φstart, φextent — longitude arc, measured counter-clockwise from φstart; φextent is 2π when the points wrap the full circle

PartialFSHT.bounding_box — Function
bounding_box(θ, φ) -> SphereBox

Exactly minimal box containing the points. O(n log n), dominated by the sort needed for the largest-circular-gap scan in longitude.

A colatitude interval that reaches either pole forces the full longitude range, since every longitude is arbitrarily close to the pole; reporting a narrow arc there would be wrong rather than merely loose.

PartialFSHT.partition_boxes — Function
partition_boxes(θ, φ, costfn; maxboxes=8) -> Vector{Vector{Int}}

Split the point set into boxes while the predicted cost falls. costfn(box, npts) returns a cost estimate for one box, so the split rule is driven by the calibrated model rather than by tuned thresholds.

Splits are taken at the largest gap in colatitude or longitude, which is the only cut that can shrink a box's extent without discarding points. A cut is kept only if it lowers total predicted cost, so a compact patch stays a single box, a band stays a single box (a band has no interior gap to cut), and genuinely disjoint components separate.

source
PartialFSHT.shannon_number — Function
shannon_number(lmax, box) -> Real

N_S = (lmax+1)² · f_sky: the number of degrees of freedom of a degree-lmax field that a region of this size can constrain (Simons, Dahlen & Wieczorek, SIAM Rev. 48, 2006). This is the ceiling on what any inversion from data in box can recover, independent of method.

source
PartialFSHT.spectral_resolution — Function
spectral_resolution(box) -> Real

Δℓ ≈ π/Λ with Λ the box's larger angular extent: the finest degree separation the geometry can distinguish, i.e. the width of the mode-coupling kernel a region of this size imposes. Band-powers finer than this are not resolved no matter how many points are supplied.

source
PartialFSHT.StretchGeometry — Type
StretchGeometry{T}

Periodisation of a colatitude interval, and the bandlimit it supports.

  • kind — :pole (interval touches a pole; the DFS reflection supplies smoothness there and only the far end is apodised), :interior (both ends apodised), :full ([0,π], DFS at both poles, no apodisation)
  • h — half-extent of the data in colatitude
  • period — padded period in colatitude, 2h(1+εapo)
  • K — retained bandlimit on the stretched circle
  • Θ1, σ, ΘT — data image, ES half-width, top-hat half-width, in stretched radians
source
PartialFSHT.stretch_geometry — Function
stretch_geometry(θlo, θhi, lmax, ε) -> StretchGeometry

Periodisation for data occupying θ ∈ [θlo, θhi]. Picks :full, :pole or :interior from the endpoints and applies the derived εapo/K relation. Throws when lmax·h ≤ 2|ln ε|, i.e. when apodisation would be wider than the data.

source
PartialFSHT.stretch_geometry_phi — Function
stretch_geometry_phi(φextent, lmax, ε) -> StretchGeometry

Periodisation of a longitude arc. Longitude is already periodic, so there is no pole case: an arc narrower than 2π is apodised from both sides (:interior), and a full circle needs no window at all (:full, K = lmax).

The same derivation applies verbatim with h = φextent/2, because the only inputs were the half-extent, the frequency of e^{i·freq·coordinate}, and the tolerance — none of which care which angle is being stretched. A narrow arc is exactly where the saving is largest, and it is why a patch away from a pole is still cheap without a coefficient rotation.

source
PartialFSHT.stretch_window — Function
stretch_window(geom, Θ) -> T

Window value at stretched colatitude Θ. Exactly one where the data lives, exactly zero at the period boundary, and C^∞ between: the ES bell convolved with a top-hat, evaluated from es_cdf. For :pole geometries the distance is measured from the pole (the DFS reflection makes the window automatically even there); for :interior it is measured from the centre of the period.

source
PartialFSHT.es_beta — Function
es_beta(ε) -> Real

ES shape parameter β = |ln ε|; the kernel's spectral residual is ~e^{-β}.

source
PartialFSHT.es_cdf — Function
es_cdf(β, u) -> T

∫_{-π/2}^{u} exp(β(cos t - 1)) cos t dt, the ES kernel's cumulative distribution after the substitution z = sin t. The substitution removes the square-root branch point the kernel has at |z| = 1, leaving an analytic integrand, so composite Gauss–Legendre converges to round-off instead of the O(n^{-3/2}) a midpoint rule on z would give. (A 64-point midpoint rule on z is off by ~1% — enough to make the window a different function from the one documented.)

source
PartialFSHT.next_smooth — Function
next_smooth(n) -> Int

Smallest 5-smooth integer ≥ n. Grid sizes are free to grow — oversampling only improves the trigonometric interpolation — while a large prime factor puts FFTW on a Rader/Bluestein path for nothing, so every planner-chosen size is rounded up rather than used as derived.

source
PartialFSHT.next_smooth_even — Function
next_smooth_even(n) -> Int

Smallest even 5-smooth integer ≥ n. The DFS reflection shifts longitude by Nφ÷2 grid cells to realise φ → φ+π, which is only a half-turn when Nφ is even. An odd grid makes it a shift of π(1 - 1/Nφ) instead, and the resulting seam caps accuracy at ~1e-5 regardless of the requested tolerance — Nφ = 135 shifts by 3.118 rad rather than 3.1416.

Spectral estimation

PartialFSHT.pseudo_spectrum! — Function
pseudo_spectrum!(C, plan, f, w, ws; batch=1) -> C

C̃_ℓ = (1/(2ℓ+1)) Σ_m |ã_{ℓm}|² from the windowed adjoint ã = A†(w·f). Biased by construction — spectrum removes the bias with mask_coupling!.

With ntrans > 1 the field carries several independent maps and batch selects which one's spectrum is wanted; there is no meaningful single spectrum of a batch, so it is an argument rather than a silent choice of the first member.

PartialFSHT.mask_coupling — Function
mask_coupling(Wℓ, lmax, backend=SerialBackend()) -> Matrix

Allocating form of mask_coupling!. O(L³) and depends only on the mask, so for repeated spectrum calls on one region build it once and pass it as coupling.

source
PartialFSHT.mask_coupling! — Function
mask_coupling!(M, Wℓ, lmax) -> M

MASTER mode-coupling matrix (Hivon et al., ApJ 567, 2002)

M_{ℓℓ'} = (2ℓ'+1)/4π Σ_{ℓ''} (2ℓ''+1) W_{ℓ''} (ℓ ℓ' ℓ''; 0 0 0)²

from the mask's own power spectrum Wℓ. Nothing about the unobserved sky enters — the mask is chosen, so Wℓ is known, which is why a band-power's bias is computable rather than merely bounded. O(L³), the same scaling every implementation of this kernel has; built once per mask.

source
PartialFSHT.bin_coupling — Function
bin_coupling(M, bands) -> Matrix

Bin M into band space with a (2ℓ+1) within-band weight, giving the square, invertible M_{bb'} that band-power estimation uses.

source
PartialFSHT.band_edges — Function
band_edges(lmax, Δℓ) -> Vector{UnitRange{Int}}

Degree bands of width Δℓ, the geometry's own resolution. Binning at this width is what makes the coupling matrix invertible; finer bands ask for information the region does not carry.

source
PartialFSHT.threej000_sq_log — Function
threej000_sq_log(ℓ1, ℓ2, ℓ3) -> Real

log (ℓ1 ℓ2 ℓ3; 0 0 0)², or -Inf when the symbol vanishes. Closed form for the all-zero-order Wigner 3-j symbol, through loggamma so nothing overflows:

(ℓ1 ℓ2 ℓ3; 0 0 0) = (-1)^{J/2} √((J-2ℓ1)!(J-2ℓ2)!(J-2ℓ3)!/(J+1)!)
                    · (J/2)! / ((J/2-ℓ1)!(J/2-ℓ2)!(J/2-ℓ3)!)

with J = ℓ1+ℓ2+ℓ3; zero for odd J or outside the triangle inequality. Only the square is needed, so the sign is dropped.

source
PartialFSHT.synthesis_matrix — Function
synthesis_matrix(θ, φ, lmax) -> Matrix

Dense 𝒴_R, columns in (ℓ, m) nested order. A diagnostic for small lmax only.

Cost is O(M L²), which is optimal: that is the size of the output. Running one full transform per column instead — a unit coefficient array through the ring engine, (L+1)² times — is O(M L⁴), measured with a local exponent of 3.96 in lmax, so it is worse than the O(M L³) of calling ylm per entry. Here the degree recurrence runs once per (point, order) and every degree it passes through is written straight into its column.
